New plugin `vocdoni-ui-style` (`npx @vocdoni/skills install --plugin ui-style`): builds UIs with Vocdoni's look and feel in its two visual modes, editorial (vocdoni.io) and product (vocdoni-app, with white-label support). It ships design tokens for Tailwind v4 + shadcn/ui, Chakra UI v3 and plain CSS, React components, logos, reference screenshots, runnable HTML examples, worked React recipes, step-by-step UX flows for voting and vote building, copy rules, and a brand style checker.
